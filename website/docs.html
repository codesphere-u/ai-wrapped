Install & Instant Demo

AI Wrapped uses Python 3.10+ standard library modules exclusively—no third-party packages are downloaded at runtime and zero network calls ever execute.

Zero-Install & CLI Options

v1.1.0 
uvx --from git+https://github.com/codesphere-u/ai-wrapped ai-wrapped --demo

Claude Code Plugin & Agent Skill

Install via npx skills add codesphere-u/ai-wrapped or register inside Claude Code with /plugin install ai-wrapped --marketplace codesphere-u/ai-wrapped. Then run --auto to inspect your newest download locally.

Export Your Data (30 Seconds)

Request official export archives directly from each provider and point ai-wrapped at either a single ZIP or a folder holding all three platforms.

ChatGPT & Claude

  • ChatGPT: Open Settings -> Data controls -> Export data and download the ZIP (reads single conversations.json or sharded conversations-000.json cleanly).
  • Claude: Open Settings -> Privacy -> Export Data and download your archive containing chat_messages.

Google Gemini & Merging Multiple Archives

On takeout.google.com, deselect all services and pick My Activity -> Gemini Apps (JSON or HTML). Place every archive in one directory and run ai-wrapped ~/Documents/my-ai-exports --tz local.

CLI Flags Reference

Tune year boundaries, local timezone clock charts, coding agent JSONL inclusion, or stdout JSON mode.

All Options

FlagEffect
--demoRuns the bundled 20-conversation ChatGPT/Claude/Gemini showcase.
--autoFinds the newest export archive or extracted UUID export folder in ~/Downloads.
--include-agentsAdds local ~/.claude/projects and ~/.codex/sessions JSONL transcripts.
--year YEARFilters conversations and metrics to one calendar year (e.g., 2026).
--tz {utc,local}Switches 24-hour clock charts and peak hour metrics between UTC and local timezone.
--output-dir DIRSets output folder for ai-wrapped.html, BRAIN_PORTABLE.md, and JSON (default ./ai-wrapped-out).
--jsonWrites structured analytics summary JSON to stdout.

Portable Brain (`BRAIN_PORTABLE.md`)

Switch across ChatGPT, Claude, Gemini, or Cursor in seconds by pasting one compact, secret-scrubbed Markdown brief.

Six Distilled Brief Sections

  1. Identity & Archetype Profile
  2. Response Formatting Preferences (concise bullets, tables, concrete examples, direct critique)
  3. Primary Focus Domains
  4. Recurring Vocabulary (post-secret redaction)
  5. Buried Unfinished Multi-Turn Projects
  6. Standing Assistant Guardrails

Privacy & Safety Architecture

Designed from line one so screenshots and portable briefs never leak secrets or scan unrelated home folders.

Redaction & Bounds

  • In-memory ZIP extraction: Rejects zip-slip .. entries and enforces 200 MB per compressed entry.
  • Pre-tokenization secret scrubbing: Replaces API keys, forge tokens, JWTs, Bearer headers, emails, SSNs, and card digits before keyword counting.
  • Broad-root protection: Refuses scanning ~ or / unless --allow-home is passed.
